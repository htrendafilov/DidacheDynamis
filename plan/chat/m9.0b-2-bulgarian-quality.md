# M9.0b-2 — Bulgarian answer-quality benchmark

Parent: [`../interactive_chat_plan.md`](../interactive_chat_plan.md) §15
Revisits: [`m9.0-findings.md`](m9.0-findings.md) §7a (ship no default model)
Depends on: [`m9.0b-1-estimator-calibration.md`](m9.0b-1-estimator-calibration.md) for the corpus, and on **M9.3 having shipped grounded answers**
Runs: **after M9.3.** Feeds the M9.4/M9.5 default-model decision.
Effort: half a day plus a Bulgarian reader's time

## Why this runs after M9.3, not before

It was originally bundled with the estimator work and marked "must land before M9.3 exits". That was wrong on two counts:

1. **It cannot block anything.** "Ship no default model" is already decided and shipped ([`m9.0-findings.md`](m9.0-findings.md) §7a). This benchmark can only *improve* that answer — propose a default — never invalidate it. A milestone gate that can only produce good news is not a gate.
2. **Run before M9.3, it measures the wrong thing.** M9.0's samples were bare Bulgarian questions. The product sends *grounded* turns: a question plus scripture, commentary and lexicon excerpts, with a citation contract to honour. A model that handles a bare question adequately may still mangle a cited passage, misattribute a Strong's id, or ignore the source-bound instruction. Scoring ungrounded output tells you little about the thing users will actually run.

So: run it against the real M9.3 pipeline, and let it inform the default-model decision when there is a milestone that wants one.

## What M9.0 actually established

Worth being precise, because this task exists to replace weak evidence rather than to repeat it.

Four identical Bulgarian requests to `openrouter/free` routed to **four different models**: one produced gibberish, one was a content-safety classifier that replied `"User"`, two were good. That is enough to prove `openrouter/free` is **not dependably usable** in Bulgarian — which is why no default ships.

It is not enough to rank alternatives. It was four runs of **one** prompt, scored by eye, and **the outputs were not saved**. Not saving them is the specific reason this cannot be built on.

## 1. Inputs

Reuse `bench/prompts.jsonl` from [`m9.0b-1-estimator-calibration.md`](m9.0b-1-estimator-calibration.md) — prompts **4, 5, 6 and 10**.

Prompts 4–6 are questions as written. #10 is a prose excerpt, so present it with one fixed Bulgarian instruction (for example `"Обясни този текст на прост език."`) recorded in `bench/README.md`, so the answer is still generated Bulgarian prose.

**Run them through M9.3's real context assembly**, not as bare chat messages. The point is to score what the product actually sends.

## 2. Models

- `openrouter/free` — **five runs each**, since it routes differently per call. Record the `model` each run actually reported.
- `google/gemini-2.5-flash-lite` via OpenRouter — a measured ZDR + `data_collection: deny` paid candidate. This uses only the OpenRouter key and route; it is not a direct Gemini adapter.
- One or two named free models that pass the privacy gate, if any do.

**Save every response verbatim** into `bench/quality-<date>.json`, alongside the `model` reported and the assembled context manifest.

## 3. Scoring

By a Bulgarian reader, 0–2 per axis:

| Axis | 0 | 1 | 2 |
|---|---|---|---|
| Grammar | broken | minor agreement errors | idiomatic |
| Theological sense | meaningless or wrong | vague but not wrong | accurate |
| Answered the question | no | partly | yes |
| **Citation fidelity** | cites text that was not sent, or misattributes | cites correctly but loosely | quotes and attributes exactly what was sent |

The fourth axis is new and only measurable after M9.3 — it is the main reason to wait.

A model is **eligible as a default** only if it scores ≥ 7/8 on every prompt, across every run. `openrouter/free`'s variance is the thing being measured: a single good run does not qualify it.

## 4. What the result changes

| Outcome | Action |
|---|---|
| A privacy-passing model is consistently good | Propose it as default; the owner decides. Update `m9.0-findings.md` §7a and the model picker copy |
| Only paid models qualify | **No default stands.** Record the best paid candidate as a *recommendation* in the picker — text, not a preselection |
| Nothing qualifies | No default, and the Bulgarian answer-quality caveat becomes permanent first-run copy |

## Definition of done

- [ ] `bench/quality-<date>.json` checked in with raw outputs, reported model, and context manifest per run
- [ ] Scores recorded against all four axes, by a Bulgarian reader
- [ ] `m9.0-findings.md` §7a either upheld or superseded by an owner decision, with scores attached
- [ ] Keys used are revoked
