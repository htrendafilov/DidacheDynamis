# M9.0b — Bulgarian quality benchmark and estimator corpus

Parent: [`../interactive_chat_plan.md`](../interactive_chat_plan.md) §15
Follows: [`m9.0-findings.md`](m9.0-findings.md) §5a, §7a
Blocks: nothing in M9.2's shell. **Must land before M9.3 exits.**
Effort: half a day

## Why this exists

M9.0 produced two conclusions it did not have the evidence to support, and one it did:

- **Supported:** `openrouter/free` is not dependably usable in Bulgarian. Two of four samples were unusable, one of them from a content-safety classifier. That is enough to refuse it as a default.
- **Unsupported:** any ranking of the alternatives. Four runs of *one* prompt, scored by eye, with **the outputs not saved**.
- **Unsupported:** that the token estimator is calibrated. Six samples against two models of the same family, when the router demonstrably answers from Cohere and NVIDIA models too (`m9.0-findings.md` §9).

Both gaps need the same thing — a small fixed corpus that is checked in and re-runnable. Building it once serves both.

**This is deliberately not a research project.** Ten prompts, a handful of models, a results file. If it grows past half a day, cut models, not rigour.

## Deliverables

1. `plan/chat/bench/prompts.jsonl` — the corpus. Checked in.
2. `plan/chat/bench/results-<date>.json` — raw outputs and `usage` per (prompt × model). Checked in.
3. `plan/chat/bench/README.md` — how to re-run, and the scoring rubric.
4. Updates to `m9.0-findings.md` §5 (divisors) and §7a (default-model decision) with the evidence.

## 2. Estimator calibration — closes `m9.0-findings.md` §5a

Send every prompt through OpenRouter with `max_tokens: 1` and `usage: {include: true}`, and record `usage.prompt_tokens`. No direct provider credential is used.

Pin **one model per tokenizer family**. The point is family coverage, not model count:

| Family | Suggested pin | Why |
|---|---|---|
| Gemini tokenizer family | `google/gemini-2.5-flash-lite` **through OpenRouter** | Already measured; the control |
| Llama / Nemotron | any `nvidia/nemotron-*` free entry | Answered `openrouter/free` requests in §9 |
| Cohere | `cohere/north-mini-code` | Same |
| Qwen | any current Qwen entry | Third major family in the free pool |

Record `chars / prompt_tokens` per (prompt × family). Then either:

- **Confirm** the `1.15` multiplier in `chat/tokens.ts` covers the worst case across all four families — and replace the comment "covers other tokenizer families" with the measurement that proves it; or
- **Raise it** to whatever the worst case requires, and say so in the same comment.

**The estimate must never be below actual on any sample.** That is the existing exit criterion and it does not change.

If a family cannot be measured, `m9.0-findings.md` §5a option (b) applies: constrain the model picker to measured families and treat the rest as unsupported.

## 3. Bulgarian quality — closes `m9.0-findings.md` §7a

Run prompts 4, 5, 6 and 10 as real questions (not `max_tokens: 1`) against:

- `openrouter/free` — **five times each**, since it routes differently per call. Record the `model` each run actually reported.
- `google/gemini-2.5-flash-lite` via OpenRouter — a measured ZDR + `data_collection: deny` paid candidate. This uses only the OpenRouter key and route; it is not a direct Gemini adapter.
- One or two named free models that pass the privacy gate, if any do.

**Save every response verbatim.** The absence of saved outputs is the specific reason M9.0's §7 cannot be built on.

Score each on three axes, 0–2, by a Bulgarian reader:

| Axis | 0 | 1 | 2 |
|---|---|---|---|
| Grammar | broken | minor agreement errors | idiomatic |
| Theological sense | meaningless or wrong | vague but not wrong | accurate |
| Answered the question | no | partly | yes |

A model is **eligible as a default** only if it scores ≥ 5/6 on every prompt, across every run. `openrouter/free`'s variance is the thing being measured — a single good run does not qualify it.

## 4. What the result changes

| Outcome | Action |
|---|---|
| A privacy-passing model is consistently good | Propose it as default; the owner decides. Update `m9.0-findings.md` §7a and `m9.2-workspace-and-provider.md` §8 |
| Only paid models qualify | **No default stands** (current state). Record the best paid candidate as a recommendation in the picker, not a preselection |
| Nothing qualifies | No default, and the Bulgarian-answer quality caveat becomes a permanent part of the Assistant's first-run copy |

Note that "no default" is already the shipping decision, so **this benchmark cannot block M9.2**. It can only improve on the current answer.
